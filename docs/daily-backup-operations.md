# Daily Backup Operations

تعمل النسخة الاحتياطية تلقائياً كل يوم عند الساعة 1:00 فجراً بتوقيت اليمن، أي عند الساعة 22:00 بالتوقيت العالمي في اليوم السابق. تستخدم المهمة المنشورة المسار المؤمّن `/api/scheduled/daily-backup`، ويحفظ النظام معرّفها في إعداد النسخ الاحتياطي حتى يمكن إيقافها أو تعديلها لاحقاً.

النسخ التي ينشئها النظام تلقائياً والنسخ التي ينشئها المالك يدوياً لا تُحذف من التطبيق. يستطيع المالك تنزيل أي نسخة من الإعدادات، وينبغي تنزيل نسخة يدوية إلى جهاز موثوق قبل أي تعديل تاريخي كبير أو عملية استعادة.
