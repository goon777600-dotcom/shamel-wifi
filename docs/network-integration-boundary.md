# حدود الربط المستقبلي مع جهاز الشبكة

لا تنفذ النسخة الحالية أي اتصال تلقائي بموجّه الشبكة أو MikroTik. تظل الفواتير وسندات القبض وحالات الاشتراك بيانات إدارية ومحاسبية تحت تحكم المالك فقط.

عند اعتماد الربط لاحقاً، يكون المصدر المعتمد لتحديد الوصول هو الاشتراك: العميل، الباقة، تاريخ الانتهاء، والحالة. ولا تُرسل عملية فصل أو تفعيل إلى جهاز الشبكة إلا بعد أن يحدد المالك سياسة الربط ومعلومات الجهاز وإجراء تفويض صريح لكل عملية حساسة.

يحافظ التصميم الحالي على فصل واضح بين طبقة الاشتراكات وطبقة الحسابات، بحيث لا يؤدي إنشاء فاتورة آجلة أو تعديل رصيد الصندوق إلى قطع أو تفعيل خدمة الإنترنت تلقائياً.
